# Game Design

Hier werden die spielbaren Systeme und verbindlichen Adventure-Designregeln dokumentiert.

## Leitprinzip
Klassisches Point-and-Click-Adventure mit Erkundung, Hotspots, Inventar, Gegenstandskombinationen, Dialogrätseln und episodischen Handlungssträngen.

## Geplante Dokumente
- `gameplay.md` — grundlegender Spielablauf und Steuerung
- `puzzle_design.md` — Rätseldesign, Fairness, Hinweise, Rätselgraphen
- `inventory.md` — Gegenstände, Zustände und Kombinationen
- `dialogue_system.md` — Dialogoptionen, Bedingungen und Reaktionen
