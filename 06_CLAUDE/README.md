# Claude Workflow

Claude erhält klar abgegrenzte Aufgaben mit konkreten Akzeptanzkriterien.

## Pflichtlektüre vor jeder Aufgabe
1. `MASTER_CONTEXT.md`
2. Betroffene Story-/Game-Design-/Technikdokumente
3. Aktueller Code und README, sobald Implementierung begonnen hat
4. `07_ROADMAP/progress.md`

## Dokumente
- `tasks/TASK_002_DOCUMENTATION_CONSOLIDATION.md` — Konsolidierung der Dokumentation und Projekt-Governance
- `MASTER_PROMPT.md` — Rolle und allgemeine Arbeitsweise
- `CODING_RULES.md` — technische Regeln
- `TASK_TEMPLATE.md` — Vorlage für Einzelaufträge

## Workflow
1. Claude liest Kontext und prüft Ist-Zustand.
2. Claude schlägt bei größeren Änderungen einen Plan vor.
3. Umsetzung in kleinen, überprüfbaren Schritten.
4. Tests und Build ausführen.
5. Änderungen und Restpunkte dokumentieren.
6. Roadmap und Fortschrittsdatei aktualisieren.
